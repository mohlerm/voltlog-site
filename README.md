# Voltlog

The showcase page of Voltlog, a logbook for an electric car: trips, charging and costs in one place, on the web and
on the iPhone and iPad. Voltlog currently reads its data from Porsche Connect (the car), Zaptec (the home wallbox) and
charging invoices.

Published with GitHub Pages. All screenshots show fictional demo data, with a Macan 4S as the example car. Voltlog is
a personal project and is not affiliated with or endorsed by Porsche AG or Zaptec.

The toggle at the top shows version 2 (default) or the last version before the redesign: their screenshots are in
`assets/v2` and `assets/v1`.
