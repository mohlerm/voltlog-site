# Voltlog

The showcase page of Voltlog, a logbook for electric Porsches, shown as a preview: the full history with detailed
statistics, on the web and on the iPhone and iPad. Voltlog currently reads its data from Porsche Connect (the car), Zaptec (the home wallbox) and
charging invoices.

Published with GitHub Pages. All screenshots show fictional demo data, with a Macan 4S as the example car. Voltlog is
a personal project and is not affiliated with or endorsed by Porsche AG or Zaptec.

The version before the 2.0 redesign stays in `v1/`: it is not linked from the page and asks search engines not to
index it.
